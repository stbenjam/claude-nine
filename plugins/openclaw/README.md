# openclaw

A miscellaneous dump of random [OpenClaw](https://github.com/openclaw/openclaw)
skills stbenjam uses day to day. There is **no unifying theme** here — it is a
junk drawer of small, self-contained skills that happen to be useful and carry
no private or secret configuration. The plugin is shared by Claude Code and
Codex.

See the [main installation guide](../../README.md#installation) for Claude
Code, Codex, and standalone Agent Skills setup.

## Notes

These skills were originally written for a personal OpenClaw workspace and then
scrubbed for public use. They assume common tools are on `PATH` (`python3`,
`ffmpeg`, Playwright, etc.) as noted in each skill. Nothing here stores
credentials or personal data — adapt the defaults to your own setup.
