# Show today's events

Use `icalBuddy` through the `calendar` skill to retrieve today's events. Exclude
holiday calendars unless the user asks for them, group results by calendar,
and present start/end times, titles, locations, and notes when available. Say
when no events are scheduled or when Calendar access is unavailable.
