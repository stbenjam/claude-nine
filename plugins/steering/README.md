# steering

Three-letter skills for agent wrangling.

See the [main installation guide](../../README.md#installation) for Claude
Code, Codex, and standalone Agent Skills setup.

- `/wtf` — explain reasoning, evidence, assumptions, and tradeoffs
- `/nah` — propose three different approaches and recommend one
- `/lfg` — implement using reasonable defaults without unnecessary questions
- `/wow` — raise a frontend redesign to an award-worthy bar
- `/cut` — make the response terser without losing substance
- `/ask` — pause and ask the questions needed for a high-quality solution

Inspired by [`bro` from dmmulroy/skills](https://github.com/dmmulroy/skills/blob/main/bro/SKILL.md).
