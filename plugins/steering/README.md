# steering

Compact invocable skills for steering direction, explanations, clarification,
brevity, execution, and frontend quality in Claude Code and Codex.

- `/steering:nah` — propose three different approaches and recommend one
- `/steering:wtf` — explain reasoning, evidence, assumptions, and tradeoffs
- `/steering:ask` — pause and ask the questions needed for a high-quality solution
- `/steering:cut` — make the response terser without losing substance
- `/steering:lfg` — implement using reasonable defaults without unnecessary questions
- `/steering:wow` — raise a frontend redesign to an award-worthy bar
