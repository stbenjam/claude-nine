# Similar books

Ask for a reference title when it is missing. Use the selected backend to find
unread books that match, in descending confidence:

1. the same author;
2. the same or a related series;
3. shared tags, shelves, or genre indicators;
4. a similar page count; and
5. a similar rating.

Explain the evidence for each match and distinguish books in the user's
library from outside recommendations. Use web search for community suggestions
only when available and useful, and label those suggestions separately. Be
transparent when the source has limited metadata.
